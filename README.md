# ITMEAS v2.1

**Intelligent Trend Monitor & Economic Analysis System**

A Streamlit MVP for monitoring demo trend data, visualizing changes, and generating a simple five-day forecast.

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deployment

This repository is ready for Streamlit Community Cloud. Deploy from the `main` branch with `app.py` as the entry point.

> Note: v2.1 currently uses generated demo data. Real social-media and economic APIs can be connected in a later stage.
